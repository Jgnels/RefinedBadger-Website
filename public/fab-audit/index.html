Sanitized sample excerpt

A useful finding ends in a test.

This excerpt uses a real RefinedBadger finding while withholding private paths, account details, licensed content, and proprietary catalog data.

Finding RB-ENV-04

Potential modular environment family

Promising · not visually verified

Evidence

Related owned Hivemind products repeatedly surfaced across environment-capable profiles and covered complementary modular-environment roles.

Inference

Hivemind may form a powerful reusable environment family. Metadata alone does not prove material, scale, art-direction, or performance compatibility.

Recommended test

Timebox one small playable slice. Record import friction, modular fit, scale, material coherence, missing connectors, and runtime performance before expanding scope.

Execution-grade prompt excerpt90-minute cap
OBJECTIVE
Test whether one owned modular environment family can produce a coherent playable slice.

EVIDENCE REQUIRED
Import results, scale/material observations, missing pieces, performance capture, screenshots.

STOP CONDITIONS
Do not buy assets, build replacement systems, or expand beyond one representative slice.

RETURN
Pass / conditional / fail, evidence, unresolved risks, and the exact next action.
